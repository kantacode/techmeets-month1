# techmeets month1

TechMeets 1か月目（Week 1〜5）の学習で作ったファイルをまとめたリポジトリです。

## フォルダ構成

| フォルダ | 内容 |
|---|---|
| `week1/` | HTML の基本 |
| `week2/` | HTML / CSS の練習（experiment-1〜4） |
| `week3/` | JavaScript・PHP の練習、お問い合わせフォーム（`contact/`） |
| `week4/` | PHP + MySQL の CRUD アプリ（ユーザー管理・記事投稿） |
| `postman/`, `.postman/` | Week 5：Postman で JSONPlaceholder の API を叩いたときのリクエスト |

各週の詳しい内容は、それぞれのフォルダにある `README.md` を見てください。

## 使っている技術

- HTML / CSS / JavaScript
- PHP
- MySQL（Docker で起動）
- Postman
- Git / GitHub

## 動かし方

- **HTML のファイル**：VS Code の Live Server で開きます。
- **PHP のファイル**：VS Code の PHP Server で開きます（Live Server では動きません）。
- **Week 4**：Docker で MySQL を起動する必要があります。手順は [week4/README.md](week4/README.md) にあります。
