# お問い合わせフォーム

## 作成したフォームの概要

PHP で作ったお問い合わせフォームです。`contact.php` の1ファイルだけで、入力画面と確認画面の両方を表示します。

- **入力項目**：名前、メールアドレス、件名、メッセージ
- **バリデーション**：全項目必須。メールアドレスは形式もチェックする
- **XSS対策**：画面に出す値はすべて `htmlspecialchars()` でエスケープする
- **送信成功時**：入力内容を確認画面に表示する

### 動かし方

VS Code の PHP Server で起動し、ブラウザで `contact.php` を開きます。

## 工夫した点

- **エスケープを関数にまとめた**：`h()` という短い関数を作り、出力のたびに `htmlspecialchars($str, ENT_QUOTES, "UTF-8")` を書かなくて済むようにした。書き忘れも防げる。
- **スペースだけの入力を防いだ**：`trim()` で前後の空白を消してからチェックしている。
- **メールの形式チェックに PHP の機能を使った**：`filter_var($email, FILTER_VALIDATE_EMAIL)` を使い、自分で正規表現を書かずに済ませた。
- **エラーをまとめて表示する**：エラーを配列に集め、足りない項目を一度に全部表示する。
- **エラー時も入力内容が消えない**：フォームの `value` に入力値を戻しているので、もう一度最初から書き直さなくてよい。

## 学んだこと

- **AIが書いたコードも、そのまま信じずに自分で確かめることが大事だと学んだ。**
  comment.php はAIが書いたコードだったが、「名前を入れても必ずエラーになる」「`<script>` がそのまま実行される」「コメントが空でも投稿できる」という3つの問題があった。
  見た目はちゃんと動いていそうでも、空のまま送信したり、わざと `<script>` を入力したりして試さないと、問題には気づけなかった。
- 次からは、AIにコードを作ってもらったら「依頼する → 読む → いろんな入力で試す → おかしければ直してもらう」の流れで確認したい。
