# AIコードのバグ修正（comment.php）

- `comment.php` … 修正前の、問題のあるコード
- `comment_fixed.php` … Claude Code と一緒に修正したコード

## 見つけた問題点

### 1. 条件分岐の演算子が間違っている
`if ($name = "")` は比較ではなく **代入** になっていた。

実際に動かすと、名前を入力しても **名前が消えて「さんのコメント:」とだけ表示された**。`$name` に空文字が代入され、空文字は `false` 扱いになるので、毎回 `else` 側に進んでしまう。そのため、名前が空でもチェックが効かない。

### 2. XSS対策（htmlspecialchars）がない
`$name` と `$comment` をそのまま出力していた。コメントに `<script>alert("攻撃")</script>` と入力すると、HTML として実行されてしまう。

### 3. 空のコメントも投稿できてしまう
名前のチェックはあるが、コメント欄が空のままでも投稿できた。

## 修正した内容

| 問題 | 修正前 | 修正後 |
|---|---|---|
| 1. 演算子 | `if ($name = "")` | `if ($name === "")` |
| 2. XSS対策 | `echo "<p>" . $comment . "</p>";` | `htmlspecialchars($comment, ENT_QUOTES, "UTF-8")` で変換してから出力 |
| 3. 空のコメント | チェックなし | `elseif ($comment === "")` を追加 |

### 追加で直したこと
修正版を試したところ、**名前やコメントにスペースだけを入れると、空なのに投稿できてしまう**ことに気づいた。そこで追加で修正を依頼し、`trim()` で前後の空白を消してからチェックするようにした。

### 確認したこと
| 入力 | 結果 |
|---|---|
| 名前とコメントを入力 | 「〇〇さんのコメント:」と表示される |
| 名前が空 | 「名前を入力してください。」 |
| コメントが空 | 「コメントを入力してください。」 |
| 名前やコメントがスペースだけ | 空と同じエラーが出る |
| `<script>alert("攻撃")</script>` | 実行されず、文字としてそのまま表示される |

## 学んだこと

- **解答や説明も、実際に動かして確かめないと本当のことはわからないと学んだ。**
  解答には「`if ($name = "")` だと、常に『名前を入力してください』と表示される」と書いてあった。でも実際に元のコードを動かしてみると、名前を入力しても **名前が消えて「さんのコメント:」とだけ表示された**。説明と逆の動きだった。
- **なぜそうなるのか調べて、PHP では空文字が `false` として扱われることを知った。**
  `$name = ""` は `$name` に空文字を入れる「代入」で、if はその結果（空文字）で判定する。空文字は `false` 扱いなので、毎回 `else` 側に進み、空になった名前が表示されていた。
- `=` を1文字間違えただけでもエラーは出ないので、次からは if の中の `=` と `===` に気をつけたい。
